# Notification Priority System


The system processes notifications and prioritises them based on:
- Notification type
- Recency

Priority Order:
1. Placement
2. Result
3. Event

The project contains:
- Stage 1 Backend Logic
- Stage 2 React Frontend
- Logging Middleware

---

# Technologies Used

## Frontend
- React
- Vite
- Material UI
- Axios

## Backend / Logic
- Node.js
- Axios

---

# Features Implemented

## Stage 1
- Fetch notifications using API
- Protected API authentication using Bearer Token
- Priority sorting logic
- Top 10 notifications
- Timestamp-based sorting
- Logging middleware integration

## Stage 2
- Responsive React application
- Material UI components
- Notification cards
- Filter by notification type
- Top N notifications
- Viewed / unviewed notifications
- Mobile responsive layout
- API integration using Axios
